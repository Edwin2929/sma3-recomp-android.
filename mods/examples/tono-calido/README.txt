Tono cálido — ejemplo para SMA3 Recomp Android 0.10.4 o posterior

Importa este archivo .gbamod desde Atrás > Mods > Importar mod.
Se instala desactivado. Actívalo en su ficha para ver el cambio.
Al activar otro perfil se desactiva el anterior; no se acumulan perfiles.
Desactivar o eliminar el mod recupera los colores sin modificar la partida.

Este ejemplo contiene solamente datos de una transformación de color.
No incluye gráficos, ROM, BIOS, música, código nativo ni archivos del juego.
Consulta docs/MODS.md en el repositorio para crear otros perfiles compatibles.
