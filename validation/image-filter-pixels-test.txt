SMA3 0.10.3-beta — image filter pixel specification tests

Implementation: independent RGB24 Scale2x / Scale3x rules from https://www.scale2x.it/algorithm
Coverage: all 21,147 equality partitions of a 3x3 neighborhood, for both algorithms.
42,294 neighborhood cases; 18 complete images; 2,322,137 assertions per run.
Complete-image sizes: 1x1, 1x9, 11x1, 2x2, 3x5, 7x3, 240x160, 347x160, 356x160.
Checks: edge replication, unaligned output, untouched source, output guard bytes,
overlap rejection, short buffers, null pointers, invalid/overflow dimensions and IDs.

Release: PASS (-O2 -Wall -Wextra -Werror)
AddressSanitizer + UndefinedBehaviorSanitizer: PASS (-O1 -g; leak detection disabled).
This is a host-only pixel test; no Android device or GPU is exercised.
